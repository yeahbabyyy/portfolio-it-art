# Portfolio | Inżynieria Oprogramowania & Sztuka

Gotowy projekt portfolio z trójwarstwowym efektem Parallax 3D oraz widmowym rozpływaniem się grafiki wektorowej (`.svg`) we mgle.

## Jak otworzyć i uruchomić w VS Code:
1. Rozpakuj archiwum `portfolio-it-art.zip`.
2. Otwórz VS Code i wybierz **File -> Open Folder...** (wskaż folder `portfolio-it-art`) lub kliknij dwukrotnie plik `portfolio.code-workspace`.
3. Otwórz terminal w VS Code (`Ctrl + ~`) i zainstaluj zależności:
   ```bash
   pip install -r requirements.txt
   ```
4. Uruchom serwer (klawiszem **F5** w VS Code lub komendą w terminalu):
   ```bash
   python main.py
   ```
5. Otwórz w przeglądarce: [http://127.0.0.1:8000](http://127.0.0.1:8000)
